# S01 lower bound (Lean 4)

For every n ≥ 4, every route of the 14 `ac-r2-v1` move codes from

S01(n) = (y⁻¹x⁻¹yx⁻¹yx, y⁻ⁿx⁻¹yⁿ⁻¹x)

to (x, y) has length at least 3 + ⌊(n−1)/2⌋.

Main theorem: `Floor.s01_floor`. For n = 4..11 these are the official puzzle presentations (checked in `Floor/S01.lean`). This is a lower bound only; it does not prove or disprove AC or Stable AC.

## Proof idea

Conjugations: let H(R,k) be generated by conjugates of the relators by words of length ≤ k. Each single-letter conjugation costs at most one unit of k; other moves preserve H. An action on ℤ shows y ∉ H(S01(n),k) when 2k+2 < n, forcing ⌊(n−1)/2⌋ conjugations.

Other moves: the exponent-sum matrix needs at least three inversions or multiplications to reach the identity.

## Build

In SAIR's `competition/tools/lean` (Lean 4.29.1, Mathlib `5e932f97dd25535344f80f9dd8da3aab83df0fe6`), add `Floor/` and append to `lakefile.toml`:

```toml
[[lean_lib]]
name = "Floor"
globs = ["Floor.+"]
```

```sh
MATHLIB_NO_CACHE_ON_UPDATE=1 lake update
lake exe cache get
lake build Floor
```

Axioms: `propext`, `Classical.choice`, `Quot.sound`.
